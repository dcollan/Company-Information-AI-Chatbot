# AI-Emulator-Chatbot
AI Emulator Chatbot creating using Python, Langchain, SQLite3, Streamlit, and OpenAI API Key. Chatbot is designed to query databases using Natural Language Processing Units.

# How to Run
1) Clone repository
   git clone https://github.com/dcollan/AI-Emulator-Chatbot.git
2) Open project in PyCharm Professional
3) CD to folder
   cd AIEmulator
4) Navigate to 'secure.env' file. Necessary: OpenAI subscription needed for API key credits. Once having the API key, copy from OpenAI website, and replace text 'add your open ai key here' with API Key
5) Run Streamlit command in terminal
   'streamlit run main.py'
6) Chatbot will open in localhost with new UI
