# AI-Emulator-Chatbot
Provided the database of a company, AI Chatbot will answer questions about the company for you. Created using Python, Langchain, SQLite3, Streamlit, and OpenAI API Key. Chatbot is designed to query through the database using Natural Language Processing.

# How to Run
1) Clone repository
   git clone https://github.com/dcollan/AI-Emulator-Chatbot.git
2) Open project in PyCharm Professional
3) CD to folder
   cd AIEmulator
4) Create 'secure.env' file inside of folder. Indicate inside of file:
   
   OPENAI_API_KEY=(insert OpenAI API key here)
   Necessary: OpenAI subscription needed for API key credits. Once having the API key, copy from OpenAI, and then insert

6) Run Streamlit command in terminal
   'streamlit run main.py'
7) Chatbot will open in localhost with new UI
